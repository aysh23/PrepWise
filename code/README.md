# Code directory

The application source remains in its existing root-level structure; this README is an index so the repository follows the Milestone 2 folder convention without duplicating or moving working source files.

- Frontend: `src/` (React/Vite)
- Backend: `server/src/` (Express API, prompts, Groq integration, schemas and validator)
- Backend tests: `server/test/`
- Frontend service tests: `src/services/planGenerationService.test.js`

Run backend checks from `server/` with `npm ci`, `npm test` and `npm run build`. See the root README for full setup instructions.
